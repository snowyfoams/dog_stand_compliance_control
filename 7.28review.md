# 2026-07-28 Review — DOG5 Proprioceptive EKF, VMC, and Hardware Validation

## Headline
Built a proprioceptive state estimator (EKF), a whole-body Virtual Model
Controller (VMC) in simulation, and — the day's main goal — **validated the EKF
on the real robot.** The dog stands in rigid position mode while our EKF fuses
IMU + encoders read-only, and its output matches an independent reference.

## Key hardware lessons (all fixed)
1. **Input-lost latches** = the 2.8 ms EKF+VMC ran inside the 10 ms CAN sweep.
   Fix: move EKF+VMC to a **worker thread** (numpy releases the GIL → CAN sweep
   stays ~5 ms). Decimation-in-loop alone was not enough.
2. **ENOBUFS (TX queue full)** = send-bursting after a GIL stall. Fix: **tolerate
   tx failures** (resend next sweep) + **resync the pace deadline** after a stall.
3. **`sudo` breaks the IMU import** ($HOME=/root). Run without sudo; bridge path
   is now `__file__`-relative.
4. **Compliant balance from the splayed crouch is hard**; a **rigid position
   hold is stable** — the right tool for EKF validation.
5. EKF innovations are clean and per-leg offsets < 0.2 mm → hardware calibration
   (encoder zeros, link lengths, IMU mounting) is good.
